# Checklist (English)

A quick checklist to apply per module before merging:
- [ ] All README/TODO/CHANGELOG updated to English where applicable
- [ ] All Javadocs present for public classes & methods (author/since/version/email header)
- [ ] No log messages in French (except intentional CLI prompts)
- [ ] Identifiers follow Java naming conventions and English terms
- [ ] JaCoCo coverage generated and critical public methods covered
- [ ] Checkstyle/PMD configured in CI
