# Core Module README (English draft)

Module: core
Role: Infrastructure and DTOs. Provides JSON mapping utilities, core DTO classes (PcgCoreDTO, PcpCoreDTO, JournalDTO), abstract repository contracts and test utilities.

How to build & test
```bash
cd core
mvn clean test
```

Key points
- All Javadocs and logs in this module MUST be English (US).
- This module contains serialization/deserialization pipelines used by other modules.

Links
